## 🚀 Getting Started

### Prerequisites
- Node.js 22.13.0+
- pnpm (or npm/yarn)

### Installation

```bash
# Clone the repository
git clone https://github.com/mit4o4/sajjad-portfolio.git
cd sajjad-portfolio

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

The application will be available at `http://localhost:5173`

### Build for Production

```bash
pnpm build
pnpm preview
```

## 🎨 Customization

### Updating Content
All content is managed through locale files:
- **Arabic**: `client/src/locales/ar.json`
- **English**: `client/src/locales/en.json`

### Adding Projects
Update the `projects` array in `client/src/components/PortfolioSection.tsx` with new project details and images.

### Changing Theme
Theme configuration can be modified in `client/src/contexts/ThemeContext.tsx`
